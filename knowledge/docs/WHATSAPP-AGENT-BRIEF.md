# Vyra — WhatsApp AI Rental Sales Assistant

## Purpose

A reliable WhatsApp AI assistant that helps Dubai luxury and exotic car-rental businesses answer enquiries, collect rental details and move customers toward bookings while keeping salespeople in control of commercial commitments.

## Initial Focus

- Receive WhatsApp enquiries.
- Answer using approved operator information.
- Collect rental details.
- Check trusted inventory sources.
- Support approved quote details.
- Create human handoffs.
- Track enquiry stage and ownership.

## Human Control

Humans retain control over:
- Discount exceptions.
- Eligibility exceptions.
- Payment verification.
- Final booking confirmation.

## Core Principles

- Approved data determines facts.
- AI must state when it cannot verify information.
- Customer context should survive sessions.
- One handler controls replies at a time.
- Handoffs require ownership and next actions.

## Current Product Direction

Start with WhatsApp text enquiries and human handoff. Expand only after the core workflow is dependable.
